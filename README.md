# 🏠 Boston House Price Prediction

A machine-learning project exploring house-price prediction, with notebooks for model development and an app-oriented notebook.

## 📌 Project Overview

This repository contains notebooks related to building a house-price prediction workflow. It is a place to explore data preparation, regression modelling, and the steps involved in turning a trained model into a practical prediction experience.

## 🧰 Tools

- Python
- Jupyter Notebook
- pandas / NumPy
- scikit-learn concepts for regression and preprocessing

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/pushkarsingh88603-data/bostan-house-price-prediction_new.git
   cd bostan-house-price-prediction_new
   ```
2. Install Jupyter and common data-science libraries:
   ```bash
   pip install jupyter pandas numpy scikit-learn matplotlib seaborn
   ```
3. Launch Jupyter:
   ```bash
   jupyter notebook
   ```
4. Open `House_Price_Prediction_Model.ipynb` or `APP.ipynb` and run the cells in order.

## 📂 Project Files
